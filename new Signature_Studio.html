Privacy and usage

Open this HTML in Chrome/Edge. No install, server, or upload is required. PDFs and images are processed in browser memory. Local/Session Storage is not used. This is a visual signature/stamp editor only; it does not create cryptographic signatures, certificates, verification, or PDF password encryption.

PDF limit: 50 MB; image limit: 8 MB/25 megapixels; maximum 300 objects. Encrypted PDFs may preview but cannot be exported. Export is blocked for digitally signed PDFs so existing signatures are not damaged. Placed objects are cleared when the file changes or the page reloads.

Lightweight offline version: PDF libraries are compressed into this HTML. The browser unpacks them in memory on first load. A modern Chrome/Edge browser is required; no CDN or internet is used.
